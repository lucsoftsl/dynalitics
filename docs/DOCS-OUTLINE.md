# Documentation set: outline, owners, status and audit

Author: Olivia (QA). Date: 2026-10-31. Basis: `docs/SPEC.md` v0.4, the code in `packages/*/src`, the tests, and the three workflows. This is a plan and an audit. It does not change any document except `SECURITY.md` (mine). Corrections to documents owned by others are listed in sections 4 and 5; the owner makes them.

**Legend.** Status: **exists** (accurate enough to keep), **needs update** (exists, has false or stale statements, listed below), **missing**. Verdicts in the audit: **verified** (a named test fails if it breaks), **untested** (true as far as I can tell, no test), **false** (contradicted by code or tests), **stale** (was true or planned, no longer).

**Rule for every page.** A statement about behaviour must be backed by a test or carry the word "untested". A statement about SQL Server must carry the banner _"SQL Server has never run on a real server; unverified until the `integration (mssql)` CI job is green."_ Nothing may describe `extraColumns` or `dynalitics inspect` as working, and `tableMode: 'existing'` may only be described as "step 1" (section 3; updated 2026-10-31 after SPEC v0.4.2).
